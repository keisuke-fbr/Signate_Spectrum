# データ仕様

## ファイルパス

```
data/raw/train.csv   # 1322サンプル × 1559列（含水率あり）
data/raw/test.csv    #  550サンプル × 1558列（含水率なし）
```

## 列構成

| 列名 | 型 | 説明 |
|------|-----|------|
| `sample number` | int | サンプルID |
| `species number` | int | 樹種番号 |
| `樹種` | str | 樹種名（日本語） |
| `含水率` | float | ターゲット変数（trainのみ） |
| `9993.76781` 〜 `3999.82139` | float | 近赤外スペクトル吸光度（約1555列） |

## 読み込み方法

```python
import pandas as pd

train = pd.read_csv("data/raw/train.csv", encoding='cp932')
test  = pd.read_csv("data/raw/test.csv",  encoding='cp932')

# スペクトル列の取得
meta_cols = ['sample number', 'species number', '樹種', '含水率']
spectrum_cols = [c for c in train.columns if c not in meta_cols]
```

## 重要な注意点

- **trainとtestで樹種が完全に異なる**
- 樹種依存の特徴量エンジニアリングは過学習リスクが高い
- 樹種をグループとした交差検証（GroupKFold）が必須

## スペクトル仕様

- 測定範囲: 10000〜4000 cm⁻¹
- 分解能: 8 cm⁻¹
- 積算: 32 scan
- 測定面: 板目・まさ目・追いまさ面
- 吸光度計算: 白色板リファレンスと試料反射光の比
