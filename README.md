```
結論から言うと、このコードは**「PyTorch（CNN）が有効な場合、実行のたびに結果がわずかに変わります」**。

一方で、PyTorchが入っておらず3つのモデル（LGBM, PLS, Ridge）だけで動く場合は、結果は完全に固定されます。

原因を詳しく解説します。

1. 結果が変わる原因（PyTorch/CNN）
コード内の USE_CNN = True のルートを通る場合、以下の要素がランダム性を持ちます。

重みの初期化: CNNのレイヤー（Conv1d や Linear）の重みは、実行するたびにランダムな値からスタートします。

データのシャッフル: DataLoader で shuffle=True に設定されているため、学習時にデータを読み込む順番が毎回変わります。

Dropout: 学習中にランダムにニューロンを無効化する nn.Dropout が使われているため、これも結果に影響します。

GPUの非決定性: CUDA（GPU）を使って計算する場合、計算の高速化のために微妙な誤差（順序の違い）を許容するアルゴリズムが使われることがあり、これが最終的な予測値に影響することがあります。

```
